☀️ Fly — Ferramentas Leves para Your-Day

Bem-vindo ao Fly! Este manual foi estruturado para apresentar todas as seções e funcionalidades da ferramenta de maneira prática, direta e acessível.

O Fly foi criado por um analista de sistema de gestão ERP para outros analistas e profissionais da área. O objetivo principal é dar suporte ao dia a dia, otimizar rotinas, agilizar a aprendizagem, eliminar tarefas repetitivas ou desgastantes e liberar nosso dia para atividades mais prazerosas.

Dados

Esta seção engloba a gestão de conexões com o banco de dados e as rotinas de navegação, consulta e análise de registros.

⚠️ Importante: O Fly foi criado para conectar em bases locais, é para apoiar em auto-aprendizado. O autor não se responsabiliza pelo uso errado da ferramenta.

Ferramentas da Seção Dados

1. Perfil de Conexão com Banco de Dados

Parametrização dos perfis de acesso ao banco SQL local para habilitar as demais ferramentas da aplicação.

  • Configurações do Perfil:
    • Nome do Perfil: Identificador à sua escolha.
    • Tipo da Origem de Dados / Servidor: Padrão localhost.
    • Banco de Dados: Seleção na lista retornada após a conexão.
    • Autenticação: Usuário e senha internos do banco SQL.
    • Driver de Conexão: Driver correspondente à sua instalação.
    • Planilha de Saída: Nome do arquivo para montagem e exportação de layouts/planilhas.
  • Operações:
    • Conectar: Duplo clique no perfil ou botão Conectar. Toda a ferramenta passa a responder a este banco.
    • Trocar Perfil: Alterne facilmente para realizar análises em ambientes diferentes.
    • Excluir: Selecione o perfil, clique em Excluir e confirme.

2. Navegador de Banco de Dados

Centraliza a exploração de dados, tabelas e consultas com visões customizadas para o ambiente.

  • Visões de Tabelas:
    • Visão Lista: Relação completa das tabelas do banco.
    • Visão Treeview (2 Letras): Agrupa tabelas pelas duas primeiras letras do prefixo (ex: Família SA, Família SC).
    • Visão Módulos: Relaciona os campos via metadados de tabelas e colunas para agrupar por módulo do sistema.
  • Visão Fly (Consultas Prontas):
    • Comandos em scripts de automação do ERP / comandos DOS.
    • Exemplos de queries SQL e arquivos .ini do servidor de aplicação (útil para subir ambientes do zero).
    • Relação das funções de automação mais utilizadas.
  • Navegação e Ordenação:
    • Cruzamento automático com a tabela de índices para ajustar ordenação padrão do sistema de gestão ERP.
    • Ordenação ascendente/descendente (A-Z / Z-A) com base no campo da chave primária do banco ou chave do dicionário.
  • Performance e Filtros:
    • Exibição paginada: padrão de 500 registros (ajustável para 1.000, 5.000 ou todos).
    • Botão para limpar filtros e opção (checkbox) para ocultar colunas inteiramente vazias.
    • Exportação dos resultados para Excel.

3. Central de Consultas SQL

Interface focada no auxílio à escrita e execução de queries.

Recurso Descrição
Assistentes de Código Botões com comandos frequentes (INNER JOIN, LEFT JOIN, etc.) que inserem a sintaxe nos locais corretos.
Repositório de Queries Salva suas consultas customizadas no repositório local para reutilização rápida.
Ajuste de Editor Botões diretos para aumentar/diminuir o tamanho da fonte da área de edição.

4. Antes e Depois

Ferramenta para auditoria visual de impacto em movimentações no banco de dados.

  1. Captura Inicial: Tira uma "foto" (contagem de registros) de todas as tabelas.
  2. Execução no Sistema: Realize a operação desejada no ERP (ex: inclusão de cadastro, baixa de título).
  3. Nova Contagem: O Fly processa a contagem atualizada.
  4. Comparativo: Gera uma lista com linha do tempo em abas, destacando a diferença na quantidade de registros para identificar exatamente quais tabelas sofreram alteração.

5. Compara Tabela de Parâmetros (Local vs. Banco de Dados)

Compara a tabela de parâmetros do sistema do seu banco local contra um arquivo de extração local (.sqlite) extraído via utilitário de extração de dados.

  • Identifica parâmetros ausentes ou com valores divergentes entre bases.
  • Possibilita a aplicação de filtros por parâmetro específico.
  • Filtro dedicado para exibir exclusivamente as diferenças.
  • Exportação do comparativo em planilha.

6. Exportar Tabelas do Banco de Dados

Exporta tabelas da base conectada com suporte a regras de filtragem.

  • Filtro por Exclusão: Ignora tabelas que contenham determinados textos.
  • Filtro por Inclusão: Define apenas os prefixos de tabelas desejados.
  • Nota: Múltiplas regras de filtro podem ser informadas separando os termos por ponto e vírgula (;).

Importador de Dados do ERP

A seção Importador de Dados do ERP reúne um ecossistema completo para apoiar a rotina de carga de dados, validação e geração de layouts para o módulo de carga massiva de dados.

┌─────────────────┐     ┌──────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│ Planilha Mestre │ ──> │  Planilha Base   │ ──> │ Validação Dados  │ ──> │ Gera Layout XML │
│  (Fly Master)   │     │(Dicionário Campos)│     │  (Higienização)  │     │ & Arquivo Texto │
└─────────────────┘     └──────────────────┘     └──────────────────┘     └─────────────────┘

Detalhamento dos Componentes do Importador

Rotina Função Principal Destaques & Dicas
1. Abrir Arquivo Mestre Gerenciar o roteiro base de importação (Fly Master). Mantém a ordem de precedência técnica de tabelas (ex: Plano de Contas antes de Produtos). Possui a aba Exceção para tratar campos fora do dicionário de colunas (como adiantamentos em contas a pagar/receber).
2. Gerar Planilha Base Montar a estrutura Excel de trabalho por tabelas. Destaca campos obrigatórios em vermelho. Exibe anotações ao passar o mouse (tipo, tamanho, decimais e opções do campo de lista). Permite customizar cores e usar a função Formatador de Cabeçalho.
3. Abrir Planilha Saída Atalho rápido para a planilha de trabalho. Abre diretamente a planilha cadastrada no perfil sem navegar pelo gerenciador de arquivos.
4. Validar Dados Higienizar dados na planilha antes da carga. Converte para maiúsculas, remove espaços e acentuação, e valida campos obrigatórios. Destaca células inconsistentes com cores configuráveis para uso dos filtros das ferramentas de planilhas.
5. Gerar Layout XML Criar os arquivos XML de layout para o sistema de gestão ERP. Grava os arquivos prontos para importação no módulo configurador do sistema na pasta de output.
6. Exportar Dados da Planilha Gerar o arquivo texto final lido pelo importador de dados. Aplica separadores, formatos de data, casas decimais e códigos de layout de forma automática com base no arquivo mestre.

Geradores

Ferramentas para criação rápida de massas de dados fictícias para testes de homologação e desenvolvimento local.

1. Gerador de Empresas

Gera estruturas completas e fictícias de cadastro com base em inteligência de dados (municípios IBGE, telefones e CEPs coerentes por estado).

  • Tipos de cadastro:
    • Clientes (Pessoa Jurídica / Pessoa Física)
    • Fornecedores (Pessoa Jurídica / Pessoa Física)
    • Vendedores
    • Transportadoras
  • Nota: Para nomes de pessoas físicas, os dados gerados não incluem cálculo de CPF.

2. Gerador de Produtos

Permite alimentar cadastros de estoque com até 23 categorias de produtos (químicos, insumos industriais, mobília, material de consumo, etc.).

  • Geração de Códigos: Cria códigos aleatórios em Hexadecimal de 6 dígitos (ex: A1F39C) ou combina o tipo do produto (ex: MC) seguido pelo código Hexa.
  • Compatibilidade de Tipos: Permite selecionar o tipo de produto (ex: MP para matéria-prima, MC para consumo) alinhado à categoria.

3. Gerador de Números

Gera sequências numéricas ou códigos aleatórios para preenchimento de tabelas e testes em planilhas.

  • Suporta números sequenciais, números aleatórios e códigos Hexa.
  • Permite definir prefixos customizados e alinhamento com zeros à esquerda.

4. Gerador de Cores

Cria cores aleatórias e identifica códigos de cor para desenvolvimento de interfaces ou formatação condicional em planilhas.

  • Retorna valores em Hexadecimal e RGB.
  • Inclui seletor por paleta via biblioteca integrada.

Escritório

Utilitários de apoio geral para tarefas cotidianas de análise e documentação.

  • Calculadora RPN: Calculadora no padrão RPN (Reverse Polish Notation) com funções matemáticas básicas e financeiras.
  • Calendário do Brasil: Calendário interativo com filtro por estado brasileiro para identificação de feriados estaduais e nacionais.
    • Exibe detalhes do feriado ao clicar na data.
    • Calcula o intervalo entre duas datas com contagem de dias úteis, finais de semana, total de meses/anos e total de feriados no período.
  • Minhas Notas: Bloco de notas estruturado para centralizar anotações rápidas organizadas por cliente e tags. Possui recursos de cópia, importação e exportação de credenciais ou dados operacionais.
  • Navegador de Documentos: Explorador de arquivos com busca rápida por iniciais na pasta raiz configurada.
    • Permite expandir a árvore de diretórios, abrir documentos com o programa padrão do sistema (duplo clique) e enviar arquivos diretamente para a Lixeira.

Ferramentas

Módulos práticos de suporte técnico, simulação e automação.

1. Buscador de Arquivos

Busca avançada no sistema de arquivos local.

  • Permite filtrar por pasta inicial, múltiplos termos no nome do arquivo (separados por ;) e múltiplas extensões.
  • Busca por conteúdo (texto interno no arquivo).
  • Filtro por data de modificação e dias sem acesso.
  • Exportação dos resultados da busca para planilha.

2. Higienizador de Textos

Limpa e trata arquivos de texto brutos, removendo caracteres ocultos e tabulações indesejadas, oferecendo pré-visualização e salvamento do arquivo tratado.

3. Simulador de Dialog

Ambiente visual interativo para desenvolvimento e cálculo de coordenadas de telas do sistema de gestão ERP.

  • Contém uma janela e um botão manipulável ("Arrasta-me").
  • Exibe em tempo real as coordenadas (X, Y), largura e altura da janela e dos componentes à medida que são ajustados na tela.

4. Quiz / Case de Negócio

Jogo simulador de decisões empresariais focado no entendimento do fluxo de departamentos, custos e margem de lucro.

  • Objetivo: Ajustar variáveis de processos e pessoas para atingir o custo-alvo de um produto (ex: produção de pão) mantendo a margem de lucro e atratividade salarial.
  • Permite salvar e restaurar o progresso do jogo.

5. APIs Públicas

Central de exploração de serviços Web (utilizando a suíte BrasilAPI) para despertar insights de automação.

  • Consultas disponíveis: CEP (com coordenadas), Estados/Cidades por DDD, CNPJ, lista de Bancos, Feriados Nacionais, Previsão do Tempo e consulta de livros via ISBN.

Configurações

Painel de controle geral para personalizar o comportamento do Fly:

  • Interface e Pastas: Definição dos diretórios padrões de leitura de documentos, gravação de outputs e caminho do arquivo mestre.
  • Validações: Adição ou remoção de caracteres especiais considerados na higienização de dados.
  • Campos Globais (Aba Geral): Cadastro de campos do ERP que devem ser tratados automaticamente como CNPJ, PIS ou receber anotações de cabeçalho na geração de layouts.
  • Estilo & Tema: Customização da paleta de cores das validações e do ambiente.
  • Manutenção: Botões para restauração dos padrões de fábrica.

Recursos Adicionais (Botões)

  • Frase do Dia: Integração com a API frasesestoicas.com.br para apresentar reflexões e apoiar a prática de pausar durante o trabalho (Metodologia Pomodoro).
  • Ajuda: Conecta diretamente ao manual da ferramenta no navegador.
  • Relax: Espaço de descompressão para intervalos de solução de problemas.
    • Imagens relaxantes e integração com a API wallhaven.cc para trocar o papel de parede do computador com imagens aleatórias.
    • Mini-game de inglês para prática leve do idioma.
  • Sobre: Informações de autoria, versão, histórico de atualizações e detalhes sobre a licença de uso MIT.

  • Linguagem: Desenvolvido integralmente em Python.
  • Filosofia de Arquitetura:
    • Engenharia de Prompts e Contexto: O projeto foi desenhado com forte especialização em estrutura de prompts, modularização de código e separação rigorosa de responsabilidades (evitando arquivos monolíticos).
